# Code of Conduct

Be kind, be direct, assume good faith. Disagree with ideas, not people. No harassment,
discrimination, or personal attacks, in issues, pull requests, or anywhere else this project
is discussed.

Maintainers may edit, remove, or reject contributions and comments that do not follow this,
and may block repeat offenders. To report a problem, email the maintainer listed in
[SECURITY.md](SECURITY.md).

This is a condensed version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
